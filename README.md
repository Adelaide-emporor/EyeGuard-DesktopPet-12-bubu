# EyeGuard · Windows 护眼提醒 Agent

按 **20-20-20 规则**工作的桌面护眼工具：每连续工作 N 分钟（默认 20 分钟）提醒你看向
20 英尺（约 6 米）外休息 N 秒（默认 20 秒）。程序常驻系统托盘，平时零打扰。
计时只累计“实际使用屏幕”的时间：锁屏、屏保、关闭显示器、睡眠、会话断开或
键鼠空闲时自动暂停；恢复使用后按离开时长决定重置周期或继续剩余时间。
另有独立的**久坐提醒**：屏幕在场时间每满 30 分钟（可调），“一二”桌宠从右下角
跳出挥手提醒起身（可一键切换“布布”等角色包），确认“已起身”后站立倒计时，
结束时提示可以坐下，并统计每日站立总量。

技术栈：Python 3.10+ · PySide6 · JSON 配置 · winreg 开机自启 · QLocalServer 单实例 ·
角色包系统 · PyInstaller 单文件打包（无控制台）。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 系统托盘 | 暂停/恢复、立即休息、重置计时、设置、今日统计、退出；悬停图标显示下次休息倒计时；双击打开设置，中键立即休息 |
| 计时器 | 工作/休息循环，可暂停、恢复、重置；按“实际使用屏幕时间”累加：锁屏/屏保/关屏/睡眠/会话断开/键鼠空闲时自动暂停，恢复后按离开时长重置或继续 |
| 休息提醒 | 四种方式互斥可选：全屏置顶遮罩 / 普通窗口（可置顶）/ 仅托盘气泡 / **桌宠眨眼**（无弹窗，角色眨眼 break 秒后自动完成休息）；遮罩与窗口方式为倒计时+进度条+跳过/推迟；桌宠眨眼方式的护眼角色与专属音效均可在设置中配置 |
| 设置 | 工作时长、休息时长、推迟时长、标题正文自定义、提醒方式、置顶、声音、免打扰时段（支持跨午夜）、开机自启、测试弹窗、保存/取消/恢复默认 |
| 统计 | 今日完成 / 跳过 / 推迟 次数与累计站立时长，跨天自动清零 |
| 久坐提醒 | 屏幕在场时间每满 N 分钟（默认 30，可调 20–60）触发桌宠：**站立与坐下可分别指定角色**（一二或布布）；角色从右下角跳出，气泡“该站起来动动啦！”+ 站立音效；点“已起身”站立倒计时（默认 5 分钟），结束后**坐下角色**再次跳出提示“可以坐啦~”+ 坐下音效；离开屏幕即重置周期并收回桌宠；每日站立上限（默认 120 分钟）托盘提示一次；与护眼提醒独立计时，同时触发排队展示 |
| 桌宠角色包 | 核心程序 + 角色包架构：角色素材直接取自用户提供的原图抠像透明 PNG（程序只做跳跃位移、左右摆动、呼吸缩放、眨眼轻压，**绝不重绘角色笔画**）；启动时自动扫描 `characters/`（程序旁）与 `%APPDATA%\EyeGuard\characters\`；内置“一二”（默认）与“布布”；四个场景角色独立可配：护眼提醒 / 站立提醒 / 坐下提醒 / 常驻待机（托盘右键“切换角色”切的是常驻形象），均即时生效并自动保存；常驻待机右下角眨眼呼吸（点击穿透）；`characters/example/` 为自制角色包模板 |
| 提示音 | 护眼 / 站立 / 坐下三路提醒音独立选择（叮咚、啵灵、叮铃等程序合成的圆润卡通音效，默认三种互不相同），下拉即试听；支持导入 **wav / mp3 / m4a**（m3a 同样接受），mp3/m4a 经 MCI → Media Foundation 双通道播放，解码失败自动回退内置音；全局音量滑块（默认 80%，实时生效）；角色包可自带音效（优先于全局配置） |
| 单实例 | QLocalServer 守卫；重复启动弹提示后自动退出（提示 8 秒自动关闭） |
| 日志 | `%APPDATA%\EyeGuard\logs\eyeguard.log`，1MB 滚动 × 3 份，记录启动/休息触发/设置修改/异常 |

## 目录结构

```
EyeGuard/
├── main.py            # 入口：单实例守卫 + 顶层控制器（信号接线）
├── config.py          # AppConfig / Stats 数据模型与 JSON 持久化
├── timer_agent.py     # 计时状态机（work/paused/break，免打扰、推迟）
├── activity.py        # 屏幕活跃度监控（锁屏/屏保/关屏/睡眠/会话/空闲 → 暂停计时）

├── break_window.py    # 护眼休息弹窗（全屏遮罩/普通窗口）+ 倒计时
├── pet_window.py      # 桌宠窗口（原图变换动画：跳跃/摇摆/呼吸 + 气泡）
├── character.py       # 角色包扫描与加载（manifest.json → 透明原图/帧序列）
├── characters/        # 角色包目录：yier（一二，默认）、bubu（布布）、example（模板）
├── _prepare_characters.py  # 原图抠像脚本（去背景→透明PNG→封装角色包）
├── _smoke_test.py     # 冒烟测试（offscreen 运行：python _smoke_test.py）
├── settings_window.py # 设置对话框（保存/取消/恢复默认/测试弹窗）
├── autostart.py       # HKCU\...\Run 注册表读写
├── utils.py           # 路径、日志、单实例、免打扰判断、提示音、内置图标
├── requirements.txt   # PySide6 + pyinstaller
├── build.bat          # 一键打包脚本
└── README.md
```

## 发布说明（GitHub 分发）

- 单个 `EyeGuard.exe` **已内嵌“一二”“布布”角色包与全部内置音效**，下载后独立运行，
  无需额外文件；
- `characters/` 文件夹为可选分发内容：想让用户自定义角色时一并打包上传；
- 用户自装角色包也可放入 `%APPDATA%\EyeGuard\characters\`；
- 若升级后角色异常，删除 `%APPDATA%\EyeGuard\sounds\`（内置音效会重新生成），
  角色包缺失时日志会记录 `未找到任何角色包`。

## 快速开始（源码运行）

```bat
cd /d D:\ai_tool\EyeGuard
python -m pip install -r requirements.txt
python main.py            :: 托盘出现眼睛图标即成功
python main.py --debug    :: 额外输出控制台日志，便于排障
```

> 项目内已附带独立虚拟环境 `.venv`（避免污染系统 Python），
> 也可用 `.venv\Scripts\python.exe main.py` 运行；不需要时直接删除 `.venv` 即可。

## 打包 exe

方式一（推荐）：双击或执行 `build.bat`，产物在 `dist\EyeGuard.exe`。

方式二（手动命令，与 build.bat 等价）：

```bat
pyinstaller --noconsole --onefile --name EyeGuard main.py
:: 如有自定义图标（放在项目根目录）：
pyinstaller --noconsole --onefile --name EyeGuard --icon=eye.ico main.py
```

## 测试步骤（验收清单）

1. **托盘**：运行程序 → 托盘出现“眼睛”图标；鼠标悬停显示“下次休息 mm:ss”倒计时；
   右键菜单齐全；`--noconsole` 打包后双击 exe 无任何黑色控制台窗口。
2. **立即弹窗**：右键托盘 →“立即休息”→ 弹出全屏遮罩，大号倒计时从 20 开始递减，
   显示“请看向 20 英尺（约 6 米）外，放松眼睛 20 秒”。
3. **跳过/推迟**：弹窗中点“跳过休息”立即关闭并重新计时；点“推迟 5 分钟”关闭，
   托盘倒计时变为约 05:00。
4. **短周期验证**：设置 → 工作时长改为 1 分钟 → 保存 → 等 1 分钟自动弹窗；
   打开 `%APPDATA%\EyeGuard\config.json` 确认已写入。
5. **统计**：完成/跳过/推迟各几次后，托盘 →“今日统计...”查看计数。
6. **免打扰**：设置免打扰为“当前时间-1 分钟 至 当前时间+1 分钟”并启用 →
   到点不再弹窗，日志出现“免打扰时段…静默跳过”。
7. **开机自启**：设置中勾选开机自启 → 保存后执行
   `reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v EyeGuard`
   应看到指向 EyeGuard.exe 的命令；取消勾选后该值消失。
8. **单实例**：程序运行中再次双击 exe → 弹出“已在运行”提示（8 秒自动关闭），
   第二个进程自动退出，托盘中始终只有一份计时。
   （注：`--onefile` 打包在任务管理器中每个实例会显示 2 个进程——bootloader 父进程
   + 主程序，属正常现象；介意可改用 `--onedir`。）
9. **配置持久化**：修改设置并保存 → 退出程序 → 重新启动 → 设置仍为新值。
10. **离开检测（活跃计时）**：程序运行后记下托盘悬停显示的倒计时。
    Win+L 锁屏 1 分钟以上再解锁 → 倒计时恢复为满额 20:00，日志出现
    “离开 … 重置工作周期”；只锁屏几秒就解锁 → 同样重置（经历过锁屏即视为休息过）。
    鼠标键盘停止 30 秒 → 悬停倒计时数字停止递减（日志出现“键鼠空闲 … 暂停”）；
    恢复输入后继续倒数，且距提醒至少还有 60 秒。睡眠、关屏、断开远程会话同理：
    期间计时冻结，唤醒/点亮/重连后重新开始完整周期。
11. **久坐提醒**：设置里有“测试久坐弹窗”按钮，点击即可预览桌宠动画 →
    角色从右下角跳出挥手并播放站立音效，气泡内点“已起身”开始站立倒计时，
    结束后桌宠再次出现提示“可以坐啦~”。
    完整验证：久坐间隔设为最小 20 分钟，屏幕前连续使用 20 分钟触发桌宠；
    Win+L 锁屏几秒再解锁 → 久坐周期重置，不会立刻弹窗；托盘“今日统计...”
    可查看累计站立时长；站立累计达到设定上限时，托盘出现一次
    “每日站立上限”温和提示。
12. **提示音差异化**：设置里“护眼提醒音”与“久坐提醒音”是两个独立下拉框，
    选中即试听；默认一个“叮咚（系统）”、一个“上行三音”，听声即可分辨提醒类型。

## 图标说明

- **托盘图标**：由 `utils.build_app_icon()` 用 QPainter 现画的一只眼睛，不依赖任何
  图片文件，删掉项目里的图片程序也照常工作。
- **exe 文件图标**：默认为 PyInstaller 图标。想自定义：把 `eye.ico` 放到项目根目录，
  重新运行 `build.bat`（脚本检测到 `eye.ico` 会自动加 `--icon=eye.ico`）。

## 常见问题

- **重复启动没反应？** 单实例守卫生效了，看托盘。提示框 8 秒自动关闭。
- **全屏遮罩只覆盖主显示器**：多显示器用户如果希望覆盖所有屏幕，可在
  `break_window.py` 中遍历 `QApplication.screens()` 自行扩展。
- **睡眠/休眠后立刻弹提醒**：计时基于绝对时间，睡眠中被跳过的到点会在唤醒后补提醒。
- **杀毒软件报毒**：未签名的 PyInstaller 单文件偶发误报，加入白名单或改用
  `--onedir` 打包。
- **移动 exe 后自启失效**：注册表里记录的是绝对路径，移动 exe 后请在设置里重新
  勾选一次开机自启。
- **仅系统通知模式下没有跳过/推迟**：气泡无法交互，到时长时间自动记为完成一次休息。
- **看视频/长时间演示（无键鼠输入）会被当成离开吗？** 会：键鼠空闲 30 秒即暂停
  累计，恢复输入后继续（且保证至少 60 秒后才会提醒）。若希望看视频时也持续计时，
  把 `activity.py` 顶部的 `IDLE_PAUSE_SECONDS` 改为 `None` 重新打包即可，
  此时只有锁屏/屏保/关屏/睡眠/会话断开才会暂停。
- **休息弹窗期间锁屏/屏保了**：视为眼睛已经休息，弹窗自动关闭并按“完成一次”记账。
- **久坐提醒和护眼提醒会互相打断吗？** 不会。两套计时完全独立；若几乎同时到点，
  久坐桌宠会排队，等护眼休息窗口结束后立即出现，任意时刻最多一个提醒窗口。
- **桌宠形象是怎么来的？** 直接取自用户提供的原图抠像：`_prepare_characters.py`
  把原图去背景（洪泛填充）成透明 PNG 封装为角色包，程序动画只做跳跃位移、
  左右摆动、呼吸缩放等物理变换，**不重绘、不改变角色任何笔画与五官**。
- **提示音是机械 TTS 语音吗？** 不是。提醒音全部为程序合成的短促圆润卡通音效
  （叮咚/啵灵/叮铃等），无任何机械语音；想用自己的声音，把 wav/mp3 通过
  各提醒音旁的“导入...”按钮加入即可。角色包也可自带音效（manifest 的
  `sounds` 字段），存在时优先播放。
- **怎么添加新桌宠角色？** 复制 `characters/example/` 模板：single 型放一张
  透明背景 PNG 原图并按需调整 `animations` 参数；帧序列型（type="frames"）
  放等尺寸透明 PNG 帧列表。文件夹放到程序旁 `characters/` 目录
  （或 `%APPDATA%\EyeGuard\characters\`），重启后在“切换角色/桌宠形象”里选择。
- **看视频时久坐时间算吗？** 算。久坐按“屏幕在场”累计（未锁屏/无屏保/显示器
  开启/未睡眠），键鼠空闲不影响——看视频同样属于久坐；起身离开通常伴随锁屏/
  屏保/关屏，周期即重置。若你起身时屏幕一直保持点亮，该段时间仍会被计为久坐，
  这是无外部信号的合理近似。
